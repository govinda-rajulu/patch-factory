# Archive

`skills/` holds the assistant skill notes for patch-factory, exported verbatim on
29 Sep 2026. Links to internal workspace pages were removed and a few privacy words were
generalised; nothing else was edited. Each file starts with a comment giving its
original name and last update.

They are **historical**. The parent file (PATCH-FACTORY-BUILDS.md) contains several dated
"current main" sections; only the newest is current as of its date, and live `main` wins
over all of them. The files mention an "action book": an interactive page in the old chat
workspace that is not part of the repo and should not be recreated.

The shared engineering handbook lives in [../handbook/](../handbook/), not here.
