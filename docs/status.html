Open problem reports

What the words mean
  • Worked: the job finished without an error. For a build, a release was published or nothing new was needed.
  • Failed: it stopped with an error. "Stopped at" names the step; the grey box is the reason line the step printed.
  • Skipped (nothing to do): the scheduled check found no new patches for that app, so it did not build.
  • Stopped (cancelled) and Ran out of time: someone or something cut the run short; the result is unknown, not good.
  • Unknown: this page could not read GitHub's record. Unknown is never shown as fine.

Data comes from GitHub's own run records, written by the "Status page data" automation after each run and once a day. A green build is not a phone test.
