## What worked
- The controller pattern (docs/review/controllers): one pasted line, a gate on bytes and sha256,
  bot drift tolerated, Rule merges tolerated, a merge tree check, cleanup by preview token and
  receipt, T1 after every merge. W15e, W15f, W15h ran RESULT OK first time.
- Rehearsing every stop against fake_gh.py before handing over (seven scenarios a packet).
- Asking the owner's shell for what only it can see (pf-keys: live key tests, CodeQL alerts, the
  morphe side folder) instead of guessing; the probe turned a guess into L076 in one run.
- Reading live GitHub state before every claim (compare base...main, commit files, release lists).

## What went wrong (48 wrong calls in this chat)
- Trusting one empty API answer: "all releases gone" (call 48, L075).
- Dropping an owner ask: the tool watch (call 47, L074).
- A gate blind to a legitimate merge: the Rule merge stopped T1 (call 46, L072).
- Reports that told the owner the wrong thing (call 43 and the 22 Oct evening check).
- "17 of 17 worked" counted two fallback builds as fine (L077).
- Pattern behind most of them: a summary word ("gone", "worked", "OK") written before a second
  source agreed. Rule: a count or a verdict needs two readings, or it says "one reading".

## Techniques worth keeping
- A packet base the sandbox cannot rebuild (a bot rewrote a 2.6 MB file): build on the last main
  the sandbox can rebuild exactly, avoid every file the bots touched after it, and let the
  controller merge over that drift. Rebuild a merge commit locally only when its tree is needed.
- Check the bot-touched files of `compare/<base>...main` against the packet's files before handing over.
- Owner commands: single line, no backslashes, values captured inline, hidden key input
  (`read -rs`), a key never printed or written to disk, gh secret set from stdin.
- Never `pkill -f` a pattern that is also in your own command line (it kills the shell); kill
  by pid read from `ps`.
- Long sandbox runs go to nohup with a log; poll the log, never block a tool call on them.
- Research agents bring candidates; vendor facts are checked on the vendor's page before use
  (OmniRoute's free-tier table was months stale).
