## The bugs that mattered, and what they taught

1. **`-d` beats `-e`.** Applying a review sheet added patch names to include-patches and left
   them in exclude-patches. `selections.sh` emits every `-d` before the `-e` of the same bundle,
   so five targets refused to release. 19 contradictions across 8 files. **Check both files.**
2. **A duplicate patch name across bundles counted twice** and hid a real miss. Now aborts.
3. **`Remove Debug Info` cannot work at all**: FTL compiled it against an older patcher and it
   throws `IllegalAccessException` on `FfmMappedFile`. Quarantined with that reason.
4. **adobo's hosts blocker needs a hosts file.** `filePathOption(required=true)` and the options
   file was `[]`. It had never run before because it sat in exclude-patches.
5. **`poll.sh` could not see its own config**, so no selection change ever triggered a build.
6. **A channel mismatch is not a parser bug.** `channel: prerelease` against a provider with zero
   prereleases gives `Could not get dev release`. edge, hotstar and sonyliv all had it.
7. **`list-patches` needs `-x`.** morphe marks newer app versions experimental and hides them
   without it. A dump without `-x` made morphe's Reddit support look two years stale.
   **Govind caught this from the upstream README while I was about to write it into a ledger.**
8. **Provider age was the wrong question.** Fixed 7 Sep: `resolve.sh` warns instead of
   disqualifying, because the build already proves usability by comparing applied patches to
   requested ones by name. Age was a guess at the same thing, and disqualifying a working
   provider turns a shipping target into no target. **Govind's call, and it was right.**

## Where the risk actually is

- **The signing keystore has one copy.** Every other risk in this project is recoverable. This one
  is not, and Truecaller costs phone verifications to re-establish.
- **Public releases, not public code.** Four builds unlock paid functionality: Truecaller premium,
  MX Player Pro, AdGuard lifetime, Key Mapper premium. A takedown names the assets. `SECURITY.md`
  has the full read.
- **13 target(s) have a single candidate**: youtube, photos, truecaller-combo, primevideo, esfile, facebook, instagram, reddit, hotstar, edge, mxplayer, telegram, keymapper. If that provider stops publishing, the target has
  no fallback, because only a candidate can win a version election. Age no longer kills them, but
  a provider that breaks against a new app version still will.
- **`morphe-desktop` is unpinned on purpose**, and it is the largest accepted supply-chain surface.
