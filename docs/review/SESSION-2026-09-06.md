# Session ledger, 6-7 Sep 2026

Written by the last block of the night. Not a summary of intent: every line below was
printed by a command, not asserted.

## What was wrong, in the order it was found

1. **Applying the review sheet only edited include-patches.** Every patch it enabled was still
   named in exclude-patches, and `selections.sh` emits every `-d` before the `-e` of the same
   bundle, so `-d` won. 19 contradictions across 8 files. Five targets refused to release.
2. **Duplicate patch names across bundles** counted twice and hid a miss. 6 dropped.
3. **`Remove Debug Info` cannot work at all**: FTL's `RemoveDebugInfoPatchKt` throws
   `IllegalAccessException` against `morphe-patcher`'s `FfmMappedFile`. Identical stack on esfile
   and mxplayer, three sibling apkcleanup patches fine. Upstream compile mismatch, quarantined.
4. **adobo's hosts blocker had no hosts file.** `filePathOption(required=true, default=null)`,
   and `src/options/adobo.json` was `[]`. It had never run before because it sat in
   exclude-patches. Now ships `src/options/hosts.txt`.
5. **`poll.sh` could not see its own config.** It compared provider release dates to the newest
   release asset and never read `src/patches`, so no selection change ever triggered a build.
6. **A dead extra bundle**: facebook's second bundle had an empty include list after the
   duplicate resolution, so it was downloaded and passed as `-p` while selecting nothing.
7. **`resolve.sh` discarded the patcher's output**, which is why edge's real error took three
   wrong diagnoses to reach.

## Gates that now exist

- `.requested` ledger per bundle, and a duplicate-name abort in `selections.sh`.
- Requested-vs-applied set comparison in `build.sh`, on every target, not just exclusive ones.
- `src/patches/QUARANTINE` + `src/etc/quarantine.sh`, wired into **3. Validate**: a patch that
  SEVERE-failed cannot be re-enabled by a future sheet apply without the push going red.
- `poll.sh` treats a target's patch dirs and options file as a build source. `ci.yml` checks out
  full history so `git log` can see them, and `poll.sh` warns loudly on a shallow clone.
- `resolve.sh` prints the patcher's exit code and full output whenever no version parses.
- `resolve.sh` falls back to the stable channel when a provider ships no dev releases, and prints
  the channel flag it used. `hotstar`, `sonyliv` and `edge` all claimed `prerelease` against repos
  with zero prereleases; every `prerelease` channel in the file was audited against the provider.
- Downloaded tooling is verified by sha256: `src/build/TOOLING.sha256` + `src/build/tooling.sh`.
  pup and APKEditor abort the build on a byte mismatch. `morphe-desktop` stays unpinned on purpose.
- `connection.sh` asks `api.github.com/rate_limit` instead of downloading one Feb-2026 asset.
- `resolve.sh` reads `releases?per_page=100`; page 1 alone hid stable releases behind 90 prereleases.
- `ci.yml` cron is daily, not Friday-only. `.github/dependabot.yml` updates actions weekly.
