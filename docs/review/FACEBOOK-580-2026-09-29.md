# Facebook moves to 580.0.0.51.74 (29 September 2026)

Owner decision in chat, 29 Sep 2026: accept the new De-Vanced Facebook bundle, and apply
Disable all ads, Disable analytics and telemetry, De-Vanced Settings and Messenger install
compatibility. The remaining new Facebook patches are to be tried one at a time later.

## Why

- De-Vanced `v1.5.0-dev.1` (prerelease, 28 Sep 2026 20:32Z, commit `7c90029` "add full 580
  patch set") removed the legacy Facebook patches `Hide 'Sponsored Stories'` and
  `Hide story ads` and replaced them with a new suite whose every Facebook patch targets only
  `580.0.0.51.74` (ARM64 version code 475019344, per the release's `patches-list.json`).
- With the old ceiling `490.0.0.63.82`, `resolve.sh` found no supported version:
  `RESULT: no viable provider` in run 36497684964 (issue #105). The shadow resolver failed the
  same way but printed no reason; this PR makes it print its own.

## What changes

- `src/targets.json` facebook: `max_app_version` `490.0.0.63.82` -> `580.0.0.51.74`; note
  updated. `min_sdk_ceiling` stays 30 and is still enforced on the downloaded and finished APK.
- `src/patches/facebook-derevanced/include-patches`: the four names above. The target stays
  `exclusive`, so nothing else applies.
- `exclude-patches` keeps `Change package name`. That name is not in 1.5.0-dev.1; an exclude of
  an absent name applies nothing, and the name check reports it as stale, not as a failure.

## Not chosen, and why

- `Facebook signature compatibility` works around the app being re-signed. It does not match a
  BANNED substring, but it is the same family as the banned signature spoofs; it needs its own
  BANNED/CONFIRM review before it could be considered.
- Clean Home feed, Disable auto refresh, Download Media, Media quality controls, Reels 2x speed,
  Picture-in-picture, AMOLED dark theme, Material You theme, Open Marketplace on launch and
  Optimize Facebook: deferred, to be added one per build so a failure names one patch.

## Limits

- This is a dev prerelease, the first release of a rewrite. Breakage is more likely than usual.
- The 26 Sep exact-version APKPure admission (`490.0.0.63.82`) does not apply to 580; the
  primary APKMirror download must succeed for this version.
- No build, publication or device test has happened yet. The first build after merge is the
  first evidence, and it will update the phone's Facebook from 490 to 580 through Obtainium.
  Same-signer updates are expected to install in place; data preservation is not guaranteed.
