## Patcher

`src/build/github_patcher.py` fetches `https://api.github.com/repos/MorpheApp/morphe-desktop/releases/latest`, rejects prereleases, and has no repository pin by default; `src/build/tooling.sh` explicitly says Morphe Desktop is **not pinned**. The live release page shows newest stable [Morphe Desktop v1.20.0](https://github.com/MorpheApp/morphe-desktop/releases), 30 Oct. Action: **rebuild will pick it up automatically**; there is no pinned patcher version to compare against.

## Caveats / provider health

- Paresh's GitLab project is explicitly archived; it is not a candidate for future app-version updates.
- FTL's GitHub release page is live but says there are no releases; branch/source behavior is therefore not represented by a “newest release” value.
- Several GitHub API calls were rate-limited or failed to render; those rows are deliberately labeled **UNVERIFIED** rather than inferred from search or branch state.
- The shelf's `status.json` has app/provider/release records but does not carry a complete patch-count field. Counts above come only from the local smoke logs when available; all other counts remain UNVERIFIED.
