## Findings

- **Amazon Music and LinkedIn**: the chat first claimed, from web searches, that Amazon Music
  had one provider and LinkedIn none. The owner said both were wrong; the claims were withdrawn
  before commit. No provider is claimed here. Pick one from the generated
  [scout](onboarding/CANDIDATES-2026-10-08.md), then one "5. Add target" run adds the app.
- **MicroG** was opt-in on the page although three apps cannot sign in without it.
- **The old add form could not work end to end**: it edited a workflow file with the workflow
  token, which GitHub refuses.
- **Builds/Watch views** list job and step names only; the reason a step printed (its error
  annotation) and what the step does were not shown. The status page shows both.
- **Patcher pre-releases**: `github_patcher.py` takes latest stable on purpose; switching
  would change all 15 targets at once. Not done; the tooling watch reports newer pre-releases.
