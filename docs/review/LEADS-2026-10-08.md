# Open leads, decided (8 Oct 2026, packet W2)

Every open item from the [audit ledger](AUDIT-COUNCIL-2026-10-06.md) and the 7 Oct desk list in
[OPEN-WORK.md](OPEN-WORK.md), with a decision. Read at main `4bdb82b8` through git blobs by sha.
"Keep" means the quoted behaviour is deliberate or not worth a change; "W2" means a later packet
with the evidence named; "Open (not read)" means this session did not check the code. "Fixed in W1" rows ship in the same W2 pull request. Nothing here is phone-tested.
