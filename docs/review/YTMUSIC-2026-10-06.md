# YouTube Music target and YouTube DeArrow (6 October 2026)

Owner request in chat, 6 Oct 2026: add YouTube Music; keep DeArrow available on YouTube so it
can be toggled. Evidence: Morphe `v1.46.0-dev.8` `patches-list.json`
(https://raw.githubusercontent.com/MorpheApp/morphe-patches/v1.46.0-dev.8/patches-list.json),
read 6 Oct 2026. This is a configuration decision; nothing here is built, published or
phone-tested until a run says so.

## Target

- `ytmusic`: package `com.google.android.apps.youtube.music`, APKMirror APK, `arch: arm64-v8a`,
  Morphe prerelease channel (same provider and options as YouTube), tag prefix `yt-music`.
- Installs as `app.morphe.android.apps.youtube.music` (GmsCore support renames it, per
  `patches/src/main/kotlin/app/morphe/patches/music/misc/gms/GmsCoreSupportPatch.kt`) beside the
  stock app, and needs Morphe MicroG RE (already an opt-in companion on the page).
- Versions listed for YouTube Music in that bundle: 9.40.51, 9.39.52, 9.38.51 (experimental),
  9.20.53, 9.15.51. The build takes the newest the patcher reports with `-x`, like YouTube.
- No source fallback is admitted (`source-fallbacks.json` row, empty admissions).

turns them on and supplies an account. GmsCore support, PoToken provider and Spoof video streams
stay, matching the approved YouTube dependencies.

## YouTube: DeArrow

- Morphe renamed `Alternative thumbnails` to `DeArrow` in 1.46.0-dev.3, so the old exclusion had
  stopped matching (provider watch #144). Owner decision 6 Oct 2026: let DeArrow ship so it can be
  toggled in the app; the dead `Alternative thumbnails` line is removed from
  `src/patches/youtube-morphe/exclude-patches`. The older DECISIONS row is history.
- Other new YouTube defaults reported in #144 (Channel search, Disable auto feed refresh, Force
  fullscreen landscape, Hide status bar, Picture-in-picture button, Playback buffer, Player icon
  style, Restore original titles, Shorts icon style, Skip silence) keep shipping as Morphe
  defaults; each adds a setting. Exclude any of them by adding its exact name.
